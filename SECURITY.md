# Security Policy

## Reporting Security Vulnerabilities

Memora takes security seriously. If you discover a security vulnerability in Orbis or the Memora Browser Engine, please do **NOT** open a public issue.

Instead, please report it privately to our security team:
- **Email:** security@memora.company
- **PGP Key:** Available upon request

Please include:
- A description of the vulnerability.
- Steps to reproduce or a minimal proof-of-concept.
- Potential impact and affected versions.

We will acknowledge your report within 24 hours, provide regular progress updates, and coordinate responsible disclosure with credit.
